# L00 编辑器与环境 笔记(2026-11-09)

## 我理解的概念(自己的话,不抄文档)

场景其实就是舞台;节点是舞台演员;组件是道具(空节点 = 还没领道具的演员,站在台上但没戏份);源是原料,产物是原料被引擎加工出来的东西;资源管理器是管理 assets 下的文件;层级管理器是针对场景里节点、组件的管理;对这三者各自有用的特性可以进行修改。

## 关键操作速记

| 操作 | 怎么做 | 易错点 |
|---|---|---|
| 创建 UI 根 | 层级管理器右键 → UI 组件 → Canvas | 自带相机,数节点时别漏 |
| 改文字 | 选中 Label 节点 → 属性检查器改 string | 是组件属性,不是节点属性 |
| 预览黑屏排查 | 查是否保存 → 相机角度 → 远近裁剪 | 未保存的改动不上预览 |

## 最小示例(我做了什么)

我自己创建了 Canvas 节点,它自带摄像机;然后我添加了 2D 的 Label(MyNameLabel),修改了名字和内容;相机拍摄到 Label 节点,将它渲染到屏幕上。

## 踩坑记录(现象 → 原因 → 解决)
1. 现象:删除 Main Light 后预览没变化 → 原因:没 Ctrl+S,预览跑的是磁盘旧版本
   → 解决:改完必保存,刷新预览再下结论

2. 现象:demo 场景预览全黑,节点都在 → 原因:相机 z=0 贴太近,画面在近裁剪面以内,相机拍不到
   → 解决:相机后退 z=1000,far 加大到 2000

3. 现象:工具改名场景报"成功",文件却消失 → 原因:返回成功≠真的写入磁盘
   → 解决:操作后查硬盘验证;丢了用 git 历史恢复
