# 问题排查指南(cocos-dev 单端版)

## 排查纪律

1. **先复现,后修改**:稳定的复现步骤都没有,改了也无法验证
2. **证据优先**:报错信息/控制台日志/节点层级 三类证据先拿到,再谈假设
3. **一次一改**:一次只改一个变量,改前留回滚点(git stash/commit)
4. **二分定位**:注释掉一半逻辑看问题还在不在,快速缩小范围

## 第 0 步:确定问题属于哪一类

| 症状 | 先查 |
|---|---|
| 编辑器操作异常/资源导入异常 | 编辑器控制台报错;重启编辑器;MCP 问题查 cocos-mcp 排查表 |
| 预览白屏/卡死/报错弹窗 | 浏览器 DevTools Console(预览窗口 F12) |
| 节点不显示 | 层级管理器里节点存在吗?active 吗?位置在相机视野内吗?UITransform 尺寸是 0 吗? |
| 脚本没生效/组件报错 | 控制台红字;脚本是否正确挂到节点;类名与文件名一致(@ccclass 参数) |
| 点击/触摸没反应 | 节点有没有碰撞大小的 UITransform/Button?事件监听 on 了吗?目标节点对吗? |
| 动画不播 | AnimationClip 赋值了吗?defaultClip?playOnAwake?play() 调了吗? |
| 数据不对(分数/状态) | logic 层单测一把;打印关键变量;是否多处修改同一状态 |
| 模型加载不出来 | 路径对吗(resources 相对路径无后缀)?Bundle 配置了吗?加载回调 err 打印了吗? |
| 模型比例/朝向不对 | 资产本身的问题(原点/朝向/比例),查 game-assets 技术要求,不是代码 bug |

## 排查手册(Cocos Creator)

- **看日志三处**:编辑器 Console、预览浏览器 DevTools Console、`debug_console`(MCP,见 cocos-mcp)
- **脚本类问题**:
  - 生命周期没走:节点 active 吗?组件 enabled 吗?onLoad 里就抛错会中断后续
  - 引用丢失:@property 面板上是否 None(改字段名后序列化断链很常见)
  - this 指向:回调里用箭头函数或 bind,普通 function 里 this 不是组件
- **事件类问题**:on 了没 off(重复触发/泄漏);监听的目标节点销毁了没(僵尸监听)
- **资源类问题**:动态加载是异步的,回调时序;释放后再用 = undefined;uuid 变更(资源挪目录)导致引用断链

## 常见反模式(先自查再深挖)

- ❌ 没看报错就凭感觉改代码碰运气
- ❌ 一次改好几处,改好了也不知道哪处起效
- ❌ 看不懂报错就绕着写(换实现规避)——学习期恰恰要读懂它
- ❌ 修好了不复测原复现路径
- ❌ 踩过的坑不记进笔记(cocos-learning 踩坑记录节)

## 修复后必做

1. 原复现步骤复测通过
2. **把"现象→根因→解决"写进该阶段笔记的踩坑记录**(这是学习仓库最有价值的沉淀)
3. 若是 logic 层纯逻辑 bug,考虑补一个 Vitest 回归用例(test-development)
4. 提交 `fix(lxx): 中文描述`,只 add 相关文件(git-workflow)
