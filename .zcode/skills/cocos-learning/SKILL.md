# Cocos Creator 学习路线(cocos-dev)

## 定位

- 本仓库是纯学习工程:目标 = 掌握 Cocos Creator 3.x 客户端开发,为 NoNameEarth 项目储备技能
- 学习模式:**AI 讲解概念 → MCP 操控编辑器搭示例 → 用户亲手做练习 → 写笔记**
- 每次学习会话开头:查本技能路线表确认当前阶段 → 读 `docs/notes/` 已有笔记了解进度 → 明确本次要学的单个知识点

## 路线表 L0~L7

| 阶段 | 主题 | 目标 | 动手练习(完成标准) |
|---|---|---|---|

## 学习纪律

1. **不跳级**:当前阶段练习+笔记未完成不开下一阶段;完成标准 = **不看示例能独立重做练习**
2. **练习必亲手做**:AI 用 MCP 搭的示例只用于讲解;练习环节用户在编辑器亲手操作,AI 只指导不代劳
3. **笔记必写**:每阶段至少一篇 `docs/notes/Lxx-<主题>.md`(模板见下);不写笔记不算完成
4. **一次一个知识点**:会话内不贪多;新概念先讲清"是什么/为什么/什么时候用"再上代码
5. **跑通 ≠ 学会**:说不出"为什么这样写"就没学会,要求 AI 换角度再讲;禁止囫囵吞枣跳过去
6. **阶段完成动作**:练习验收 → 笔记落盘 → git 提交(见 git-workflow)→ 打 tag(如 `l2-ui`)

## 练习目录约定

```
assets/
└── Lxx-<短名>/           # 每阶段一个目录,如 L01-click-move/
    ├── Lxx.scene         # 该阶段练习场景
    └── scripts/          # 练习脚本(L2 起鼓励 logic/view 分目录练分层)
docs/notes/
└── Lxx-<主题>.md         # 学习笔记
```

## 笔记模板(费曼式:用自己的话讲明白)

```markdown
# Lxx <主题> 笔记(日期)

## 我理解的概念(自己的话,不抄文档)

## 关键 API 速记
| API | 作用 | 易错点 |
|---|---|---|

## 最小示例(本次练习核心代码,带注释)

## 踩坑记录(现象 → 原因 → 解决)

## 自测三问(能独立回答才算学会)
1. ...
```

## 与其他技能联动

- 练习代码怎么写 → cocos-development(分层/性能纪律)
- AI 搭示例/操控编辑器 → cocos-mcp
- 找练习用的模型/贴图 → game-assets
- 练习跑出 bug → bug-detective
- 阶段提交与 tag → git-workflow
